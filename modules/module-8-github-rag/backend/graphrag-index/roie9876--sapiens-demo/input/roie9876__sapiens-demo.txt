# Sapiens Demo — Azure Content Understanding PDF Extraction

Extract layout and structured fields from customer card PDFs using **Azure AI Content Understanding** with a pre-created analyzer (`sapiensanalyzer`).

---

### Section Prerequisites

## Prerequisites

- Python 3.9+
- Azure CLI (`az`) or Azure Developer CLI (`azd`) installed and logged in
- An Azure AI Foundry resource with Content Understanding enabled

---

### Section Azure RBAC Roles Required

## Azure RBAC Roles Required

Your resource has **local authentication (API keys) disabled** (`disableLocalAuth=true`), so all access uses **Azure AD (Entra ID) token authentication**. You must assign the correct RBAC roles to any user or service principal that needs to call the API.

### Section Required Roles

### Required Roles

| Role | Scope | Why it's needed |
|------|-------|-----------------|
| **Cognitive Services User** | AI Foundry resource | **Required.** Allows calling Content Understanding APIs (analyze documents, manage analyzers, configure model deployments). Without this role, API calls will return `403 Forbidden`. |

### Section Optional / Additional Roles

### Optional / Additional Roles

| Role | Scope | Why it's needed |
|------|-------|-----------------|
| **Cognitive Services Contributor** | AI Foundry resource | Allows managing the Cognitive Services resource itself (create/delete resources, manage keys). Only needed for admins. |
| **Reader** | Resource Group | Allows viewing the resource in Azure Portal and listing resource properties. |
| **Owner** / **Contributor** | Resource Group | Full management of resources. Typically for infrastructure admins only. |

> ⚠️ **Important:** Even if you are the **Owner** of the resource, you still need the **Cognitive Services User** role explicitly assigned to call the Content Understanding API.

### Section How to Assign the Role

### How to Assign the Role

### Section Creating the Analyzer in Azure Content Understanding UI

## Creating the Analyzer in Azure Content Understanding UI

Before running the Python script, we created a custom analyzer called **`sapiensanalyzer`** in the [Azure Content Understanding Studio](https://contentunderstanding.ai.azure.com/). This UI-based process defines what fields to extract from your documents.

### Section Step 1: Create a New Analyzer

### Step 1: Create a New Analyzer

Navigate to the Content Understanding Studio and create a new custom analyzer. Select **Document** as the content type since we are processing PDF files. Give it the name `sapiensanalyzer`.

The analyzer setup screen lets you configure the base analyzer type, description, and processing options such as OCR and layout extraction.

![Step 1 — Create Analyzer](docs/images/01-create-analyzer.jpeg)

### Section Step 2: Define the Field Schema

### Step 2: Define the Field Schema

Next, define the fields you want to extract from the customer card PDFs. For each field, specify:

- **Field name** — The key used in the output (e.g., `CustomerId`, `Company`, `Email`)
- **Type** — The data type: `string`, `number`, `date`, `boolean`, `array`, or `object`
- **Method** — How the field is extracted:
  - **`extract`** — Extracts the value as-is from the document (literal text extraction)
  - **`generate`** — Uses AI to generate/infer the value based on content understanding
  - **`classify`** — Classifies the value against predefined categories
- **Description** — A clear explanation of the field, which acts as a prompt to guide extraction accuracy

For the Sapiens customer cards, we defined fields such as `CustomerId`, `Company`, `PrimaryContactName`, `Email`, `Phone`, `Industry`, `Region`, `Status`, `Tier`, `HqLocation`, `AccountManager`, `ContractStartDate`, `ContractEndDate`, `RenewalReviewDate`, and `Currency`.

![Step 2 — Define Field Schema](docs/images/02-define-field-schema.jpeg)

### Section Step 3: Test the Analyzer

### Step 3: Test the Analyzer

Upload a sample PDF to test the analyzer directly in the UI. The studio shows the extracted fields alongside the original document, including confidence scores and bounding boxes for each extracted value.

This lets you validate and iterate on your field schema before using it programmatically. Once the results look correct, the analyzer is ready to be called from Python code.

![Step 3 — Test Analyzer](docs/images/03-test-analyzer.jpeg)

> 💡 **Tip:** You can always go back and modify the field schema in the UI. The analyzer ID (`sapiensanalyzer`) stays the same — the Python script will automatically pick up the updated schema on the next run.

    def _raise_for_status_with_detail(self, response: Response) -> None:
        if response.ok:
            return
        try:
            error_detail = ""
            try:
                error_json = response.json()
                if "error" in error_json:
                    error_info = error_json["error"]
                    error_code = error_info.get("code", "Unknown")
                    error_message = error_info.get("message", "No message provided")
                    error_detail = f"\n  Error Code: {error_code}\n  Error Message: {error_message}"
                    if "details" in error_info:
                        error_detail += f"\n  Details: {error_info['details']}"
                    if "innererror" in error_info:
                        error_detail += f"\n  Inner Error: {error_info['innererror']}"
                else:
                    error_detail = f"\n  Response Body: {json.dumps(error_json, indent=2)}"
            except (ValueError, json.JSONDecodeError):
                if response.text:
                    error_detail = f"\n  Response Text: {response.text[:500]}"
        except Exception:
            error_detail = ""

        error_msg = f"{response.status_code} {response.reason} for url: {response.url}{error_detail}"
        raise requests.exceptions.HTTPError(error_msg, response=response)

### Method in AzureContentUnderstandingClient begin_analyze_binary

    def begin_analyze_binary(self, analyzer_id: str, file_location: str) -> Response:
        """
        Begins the analysis of a single binary file using the specified analyzer.
        Uses the :analyzeBinary endpoint required by GA API 2025-11-01.
        """
        file_path = Path(file_location)
        if not file_path.exists() or not file_path.is_file():
            raise ValueError(f"File location must be a valid file path: {file_location}")

        with open(file_location, "rb") as file:
            file_bytes = file.read()

        headers = {"Content-Type": "application/octet-stream"}
        headers.update(self._headers)

        response = requests.post(
            url=self._get_analyze_binary_url(self._endpoint, self._api_version, analyzer_id),
            headers=headers,
            data=file_bytes,
        )

        self._raise_for_status_with_detail(response)
        self._logger.info(f"Analyzing binary file {file_location} with analyzer: {analyzer_id}")
        return response

    # ── Polling ───────────────────────────────────────────────────────────

### Method in AzureContentUnderstandingClient poll_result

    def poll_result(
        self,
        response: Response,
        timeout_seconds: int = POLL_TIMEOUT_SECONDS,
        polling_interval_seconds: int = 2,
    ) -> Dict[str, Any]:
        """
        Polls the result of an asynchronous operation until it completes or times out.
        """
        operation_location = response.headers.get("operation-location", "")
        if not operation_location:
            raise ValueError("Operation location not found in response headers.")

        headers = {"Content-Type": "application/json"}
        headers.update(self._headers)

        start_time = time.time()
        while True:
            elapsed_time = time.time() - start_time
            if elapsed_time > timeout_seconds:
                raise TimeoutError(f"Operation timed out after {timeout_seconds:.2f} seconds.")

            response = requests.get(operation_location, headers=self._headers)
            self._raise_for_status_with_detail(response)
            status = response.json().get("status", "").lower()

            if status == "succeeded":
                self._logger.info(f"Request result is ready after {elapsed_time:.2f} seconds.")
                return response.json()
            elif status == "failed":
                self._logger.error(f"Request failed. Reason: {response.json()}")
                raise RuntimeError("Request failed.")
            else:
                self._logger.info(f"Request in progress ... ({elapsed_time:.1f}s elapsed)")
                time.sleep(polling_interval_seconds)

"""
Sapiens Demo - Extract Customer Data from PDF using Azure Content Understanding
================================================================================
Uses the pre-created analyzer "sapiensanalyzer" to process PDF files
from the sample-demo-files/ folder and extract ONLY the fields defined
in the analyzer schema.

The Markdown output is built from extracted fields only — NOT from the
raw document layout. This means sensitive data (e.g. pricing, discounts)
that is NOT in the schema will never appear in the output.

The generated Markdown is designed to be ingested into an LLM for RAG.

Usage:
    python extract_pdf_layout.py                          # Process all PDFs

### Function get_field_value

def get_field_value(field_value: dict) -> str:
    """Extract the display value from a field based on its type."""
    field_type = field_value.get("type", "")
    if field_type == "string":
        return field_value.get("valueString", "")
    elif field_type == "number":
        return str(field_value.get("valueNumber", ""))
    elif field_type == "date":
        return field_value.get("valueDate", "")
    elif field_type == "boolean":
        return str(field_value.get("valueBoolean", ""))
    return ""

### Function build_markdown_from_fields

def build_markdown_from_fields(result: dict, pdf_name: str) -> str:
    """
    Build a clean Markdown document from the extracted fields ONLY.

    This ensures that only data defined in the analyzer schema appears
    in the output — sensitive data not in the schema is excluded.
    Ready for LLM / RAG ingestion.
    """
    if not result or "result" not in result:
        return ""

    contents = result["result"].get("contents", [])
    if not contents:
        return ""

    first_content = contents[0]
    fields = first_content.get("fields", {})
    if not fields:
        return ""

    lines = []
    lines.append(f"# Customer Card — {pdf_name}")
    lines.append("")

    # Group fields into logical sections for readability
    identity_fields = ["CustomerId", "Company", "PrimaryContactName", "Status", "Tier"]
    contact_fields = ["Email", "Phone", "HqLocation"]
    business_fields = ["Industry", "Region", "AccountManager"]
    contract_fields = ["ContractStartDate", "ContractEndDate", "RenewalReviewDate", "Currency"]

    sections = [
        ("Customer Identity", identity_fields),
        ("Contact Information", contact_fields),
        ("Business Details", business_fields),
        ("Contract", contract_fields),
    ]

    for section_title, field_names in sections:
        section_rows = []
        for name in field_names:
            if name in fields:
                value = get_field_value(fields[name])
                if value:
                    section_rows.append((name, value))

        if section_rows:
            lines.append(f"## {section_title}")
            lines.append("")
            lines.append("| Field | Value |")
            lines.append("|-------|-------|")
            for name, value in section_rows:
                lines.append(f"| {name} | {value} |")
            lines.append("")

    # Any remaining fields not in the sections above
    known = set(f for _, flds in sections for f in flds)
    extra = {k: v for k, v in fields.items() if k not in known}
    if extra:
        lines.append("## Other")
        lines.append("")
        lines.append("| Field | Value |")
        lines.append("|-------|-------|")
        for name, field_value in extra.items():
            value = get_field_value(field_value)
            if value:
                lines.append(f"| {name} | {value} |")
        lines.append("")

    return "\n".join(lines)

### Function build_fields_only_json

def build_fields_only_json(result: dict) -> dict:
    """
    Build a clean JSON with only the extracted fields — no raw markdown/layout.
    This ensures sensitive data not in the schema never appears in the output.
    """
    if not result or "result" not in result:
        return {}

    contents = result["result"].get("contents", [])
    clean_contents = []
    for content in contents:
        clean_content = {
            "kind": content.get("kind"),
            "startPageNumber": content.get("startPageNumber"),
            "endPageNumber": content.get("endPageNumber"),
            "fields": content.get("fields", {}),
        }
        clean_contents.append(clean_content)

    return {
        "status": result.get("status"),
        "result": {
            "analyzerId": result.get("result", {}).get("analyzerId"),
            "apiVersion": result.get("result", {}).get("apiVersion"),
            "contents": clean_contents,
        },
    }

### Function save_result

def save_result(result: dict, pdf_name: str) -> tuple[str, str]:
    """Save a clean JSON (fields only) and Markdown built from extracted fields."""
    os.makedirs(OUTPUT_FOLDER, exist_ok=True)
    stem = Path(pdf_name).stem
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")

    # Save clean JSON — fields only, no raw markdown/layout
    json_path = os.path.join(OUTPUT_FOLDER, f"{stem}_{timestamp}.json")
    clean_result = build_fields_only_json(result)
    with open(json_path, "w") as f:
        json.dump(clean_result, f, indent=2, ensure_ascii=False)

    # Build Markdown from extracted fields only (no sensitive data)
    md_path = os.path.join(OUTPUT_FOLDER, f"{stem}_{timestamp}.md")
    markdown_content = build_markdown_from_fields(result, pdf_name)

    if markdown_content:
        with open(md_path, "w") as f:
            f.write(markdown_content)
    else:
        md_path = None

    return json_path, md_path

def main():
    validate_env()
    client = create_client()

    # Determine which PDFs to process
    if len(sys.argv) > 1:
        # Process specific file(s) passed as arguments
        pdf_files = sys.argv[1:]
    else:
        # Process all PDFs in the sample folder
        if not os.path.isdir(PDF_FOLDER):
            print(f"❌ PDF folder not found: {PDF_FOLDER}")
            sys.exit(1)
        pdf_files = sorted([
            os.path.join(PDF_FOLDER, f)
            for f in os.listdir(PDF_FOLDER)
            if f.lower().endswith(".pdf")
        ])

    if not pdf_files:
        print(f"⚠️  No PDF files found in {PDF_FOLDER}/")
        sys.exit(1)

    print(f"\n📂 Found {len(pdf_files)} PDF file(s) to process")

    # Analyze each PDF
    results = {}
    for pdf_path in pdf_files:
        try:
            result = analyze_pdf(client, pdf_path)
            results[os.path.basename(pdf_path)] = result
        except Exception as e:
            print(f"   ❌ Error analyzing {pdf_path}: {e}")
            results[os.path.basename(pdf_path)] = {"error": str(e)}

    # Summary
    print(f"\n{'═' * 70}")
    print(f"📊 Summary: Processed {len(results)} file(s)")
    print(f"   Output folder: {OUTPUT_FOLDER}/")
    print(f"{'═' * 70}")


if __name__ == "__main__":
